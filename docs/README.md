# Hasilan Code LP

Hasilan Code の紹介ページです。`docs/index.html` 単体で表示できます。追加の依存パッケージやビルド処理は不要です。

## 確認方法

`docs/index.html` をブラウザーで開いてください。ページ内の「使い始める」から導入手順へ移動でき、端末コマンドのコピーボタンも使用できます。

## GitHub Pages で公開する場合

この変更を `main` に取り込んだ後、リポジトリの **Settings → Pages** で **Deploy from a branch**、`main`、`/docs` を選ぶと、公開ページとして使えます。公開はリポジトリ管理者による設定が必要です。

## コンテンツの根拠

説明と導入コマンドはリポジトリのルート `README.md` に合わせています。画面の描画部分は紹介用のイメージで、実際のスクリーンショットではありません。

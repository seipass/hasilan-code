FEATURES / 主な機能

開発に必要なものを、
ひとつの場所に。

指示を出して、作業を見守り、成果を確認する。複数の画面を行き来する手間を減らし、開発に集中できます。

01 / CHAT

AI チャット

モデルや推論の強度を選択。会話の内容と、AIが実行した作業の結果をその場で確認できます。

02 / TEAM

チーム実行・百鬼夜行

複数のAIに実装や検証を分担。担当ごとの進み具合や関係を図で把握できます。

03 / GOAL

目標に向けた継続作業

目標を設定するとAIが作業を継続。進行状況、入力待ち、停止などの状態を確認できます。

04 / CANVAS

設計キャンバス

アイデアを項目と線で整理。設計をファイルに書き出したり、AIへの相談に利用したりできます。

05 / WORKSPACE

開発用パネル

ファイルや動画の閲覧、文章のプレビュー、画面分割、端末操作まで一画面に集約。

06 / BROWSER

ブラウザーと検索

ブラウザー操作と、設定した検索サービスを使った情報収集にも対応しています。

GET STARTED / 導入方法

さあ、あなたの環境で
始めよう。

Node.js 22.19.0以上を用意したら、端末からインストール。初期設定を済ませ、表示された認証付きURLをブラウザーで開いてください。

AIモデルの認証またはAPIキーが必要です。各サービスの利用料金が発生する場合があります。
詳しい導入・更新手順を見る ↗

Terminal — はじめの3ステップ
$ npm install --global --ignore-scripts hasilan-code
$ hasilan-code setup
$ hasilan-code

※ ローカルの単一ユーザー向けです。AIの端末操作は起動したユーザーの権限で実行されます。信頼できる環境で使用してください。

FAQ / よくある質問

気になること。

導入前によく確認したいポイントをまとめました。

無料で使えますか？

Hasilan CodeはMITライセンスで公開されているオープンソースのソフトウェアです。利用するAIモデルや検索サービスによって、別途料金がかかる場合があります。

どんな環境で動きますか？

Node.js 22.19.0以上が必要です。Windows、macOS、Linux向けの導入・検証手順を用意しています。Linuxで端末機能を使う際には、追加のビルド環境が必要です。

会話や作業内容はどこに保存されますか？

会話、作業フォルダー、チームの状態などはローカルに保存されます。AIモデルへの通信は、設定した接続先のサービスを利用します。

AIに端末を操作させても安全ですか？

端末操作やコマンド実行には、Hasilan Codeを起動したユーザーの権限が使われます。作業を隔離する仕組みはありません。信頼できる環境で使用し、実行する操作を確認してください。

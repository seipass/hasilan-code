基盤の Pi を v1.5.0 に更新し、画面全体の整理と表示性能の改善を進めたリリースです。Hasilan Code 独自の CommandCode、Jev、チーム機能も引き続き利用できます。

## 基盤と機能

- **Pi v1.5.0 へ更新**：基盤の新しい変更を取り込み、Hasilan Code 独自の機能との統合を維持しました。
- **ホーム画面の拡充**：GitHub の活動状況、最近のセッション、使用量、プルリクエストを確認するウィジェットを追加しました。
- **チームの見通し**：概要と担当の詳細を専用サイドバーにまとめ、担当間の関係図を見やすくしました。

## 画面と性能

- 配色、文字サイズ、余白、サイドバー、設定画面、タブ、メニューの表示を整理しました。
- 外観設定から使用するフォントを選べるようにしました。
- AI 応答中の再描画、非表示の編集画面、大きな会話履歴、スクリーンショットの保持を見直し、メモリ使用量と表示の負荷を改善しました。

## 補足

この版の基盤は Pi v1.5.0（`f9a26365568127461c47a07a37dcb42c140a3ac5`）です。ライセンスは GPL-3.0-only で、Pi 由来コードの MIT ライセンス表示を同梱しています。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@0.2.0
hasilan-code setup
hasilan-code
```

Windows デスクトップ版は添付の `Hasilan-Code-0.2.0-win-x64.exe` を利用できます。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v0.2.0/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

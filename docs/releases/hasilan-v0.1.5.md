複数の AI による継続的な作業と、同じネットワーク内の別端末からの利用を中心に改善しました。

## チーム機能

- **継続するチーム**：「百鬼夜行」のチームをワークスペースに結び付け、会話を切り替えたりアプリを再起動したりしても担当と履歴を引き継げるようにしました。
- **役割分担の整理**：親 AI が目標と受け入れ条件を管理し、専門担当が実装や検証を進める構成にしました。
- **相談と引き継ぎ**：専門担当同士で作業を相談・引き継ぎでき、必要に応じて補助担当に限定した作業を依頼できます。
- **作業状況の確認**：担当の履歴や関係を確認し、待機中の担当範囲を変更できます。

## 接続と運用

- **同一 LAN からのアクセス**：`--lan` を指定すると、同じ信頼できるネットワークのスマートフォンや別の PC から接続できます。
- **接続用情報の表示**：別端末から開くための認証付き URL と QR コードを表示します。
- セッションの取り込み形式や関連文書も整理しました。

LAN 接続は暗号化されない HTTP を使用します。共有 Wi-Fi やインターネットへの公開には使用しないでください。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@0.1.5
hasilan-code setup
hasilan-code
```

GitHub Releases には配布用アーカイブとインストーラーを添付しています。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v0.1.5/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

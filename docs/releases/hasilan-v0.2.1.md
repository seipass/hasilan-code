プラグイン構成への再設計、Canvas の描画・インポート対応、Git / PR ワークフロー強化、配色とチャット操作性の全面刷新を行ったリリースです。

## 主な新機能

- **プラグイン構成と拡張対応**：ツール、セッション保存・検索、ファイル、端末、Canvas、テーマなどの組み込み機能をプラグインとして整理し、サイドバーからの有効化・無効化と外部プラグイン・パネルの読み込みに対応しました。
- **Canvas の描画とインポート**：Excalidraw 風のフリーハンド描画ツールに加え、Excalidraw（`.excalidraw` / JSON）および tldraw（`.tldr` / JSON）形式のインポートに対応しました。
- **Git・PR・セッション分割**：Git 変更のレビューと行コメント作成、インライン PR ライフサイクルカード・コンフリクト確認・CI ステータス表示、隔離 worktree を使った実行中セッションの分割に対応しました。
- **エージェントとプロバイダー**：専用の Mistral Vibe API キープロバイダー、対話型の長時間シェルプロセス実行（`shell_process`）、ツール呼び出しの並列実行、LAN モードでの Tailscale 接続に対応しました。

## 画面・操作性の改善

- **配色・ステータスバー**：`111-theme` ベースの配色と VS Code 寄りのサーフェス・構文・端末配色へ刷新し、チャット画面最下部に使用量・GitHub 状態・実行時間を表示するステータスバーを追加しました。
- **チャットと設定**：2 行構成のコンポーザー、コンテキスト内訳と手動コンパクション、編集可能なアクションプランカード、会話概要パネル、フォント・テーマ設定、内蔵ブラウザの要素調整プレビューを改善しました。
- **モバイル・デスクトップ**：モバイル画面のレイアウト、タップ領域、スクロール、iOS 入力ズームを修正し、デスクトップ版の履歴操作、非アクティブタブの休止、コンテキストメニューを改善しました。

## 主な修正

- `npm` 11.19 以降の環境で `hasilan-code setup --build-pty` が同梱 `node-pty` を確実にビルドするよう修正しました。
- macOS・Windows における隔離 worktree のパス正規化を修正しました。

## 補足

この版の基盤は Pi v1.5.0（`f9a26365568127461c47a07a37dcb42c140a3ac5`）です。ライセンスは GPL-3.0-only で、Pi 由来コードの MIT ライセンス表示を同梱しています。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@0.2.1
hasilan-code setup
hasilan-code
```

Windows デスクトップ版は添付の `Hasilan-Code-0.2.1-win-x64.exe` を利用できます。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v0.2.1/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

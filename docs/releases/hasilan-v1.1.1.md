npm への公開結果を厳密に検証するための保守更新です。配布済みアーカイブの内容を確認できるようにし、公開処理の安全性を高めました。

## 主な変更

- **公開物の整合性確認**：検証済みのアーカイブと npm で実際に取得できるアーカイブの SHA-512 を照合します。
- **公開完了の判定改善**：公開操作の受付後も、パッケージのメタデータとダウンロード内容が一致するまで確認します。
- **再実行時の保護**：同一バージョンが存在する場合、配布物が一致することを確かめてから公開処理を省略します。
- **手順書の更新**：GitHub Actions を利用した npm 公開設定と手動での確認手順を整理しました。

利用者向けの画面・機能の大きな変更はありません。主に配布と検証の仕組みを改善したバージョンです。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@1.1.1
hasilan-code setup
hasilan-code
```

GitHub Releases には配布用アーカイブとインストーラーを添付しています。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v1.1.1/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

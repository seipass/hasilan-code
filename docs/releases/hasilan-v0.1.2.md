画面の情報整理と、AI 利用状況の見やすさを改善した更新です。あわせて、配布パッケージの構成を Hasilan Code 専用に整えました。

## 画面と操作の改善

- **モデル選択**：入力欄の近くに選択パネルを表示し、現在選んでいるモデルがわかるようにしました。
- **使用量の確認**：コンテキスト使用量を開いて確認でき、保存済み会話の使用量も復元します。
- **表示の整理**：Canvas・Goal・チームの空画面にある重複説明を減らし、必要な案内は残しました。

## AI 実行と使用量

- Goal と百鬼夜行の状態保存を見直し、会話履歴の圧縮後にも必要な状態を引き継ぐようにしました。
- 共通指示とツール定義の順序を安定させ、プロンプトの再利用を考慮した構成にしました。
- 担当・モデル別のトークン数、キャッシュヒット率の集計、概算料金を確認できます。実際の API 利用料金やキャッシュ削減効果を保証するものではありません。

## 配布とバージョン

- Pi 由来の共有パッケージを `@hasilan-code/*` に整理し、配布物へ同梱しました。
- アプリのバージョン表記を **1.1.1 から 0.1.2 へ変更**しました。既存環境をこの版に切り替える際は、バージョンを指定して導入してください。
- 基盤 Pi のバージョンは 1.3.0 のままです。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@0.1.2
hasilan-code setup
hasilan-code
```

GitHub Releases には配布用アーカイブとインストーラーを添付しています。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v0.1.2/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

AI のコンピューター操作、作業先の選択、画像・動画などの扱いを拡充した更新です。

## 主な変更

- **コンピューター操作**：Jev を含む操作経路を整理し、画面情報の取得や操作結果の取り扱いを拡張しました。
- **作業先の切り替え**：ワークスペースと会話の振り分け処理を整え、指定した作業先で操作を進めるための検証を追加しました。
- **添付ファイルとメディア**：画像や動画の受け渡し、表示、入力欄での添付処理を改善しました。
- **画面の使い勝手**：チームの表示、入力欄、各種ウィジェット、表示切り替え時の動きを調整しました。
- **動作検証**：コンピューター操作・添付・ワークスペース選択に関するテストを拡充しました。

## 補足

コンピューター操作は起動したユーザーの権限で実行されます。利用する作業フォルダーと操作対象を確認してください。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@0.1.6
hasilan-code setup
hasilan-code
```

GitHub Releases には配布用アーカイブとインストーラーを添付しています。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v0.1.6/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

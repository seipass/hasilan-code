日常的な開発作業で使う画面を幅広く見直した更新です。会話、ファイル閲覧、設定、モバイル表示の操作性を中心に改善しました。

## 画面と操作

- **会話の表示**：AI の実行状況とツール操作の結果を確認しやすい表示に整理しました。
- **ファイル操作**：画像プレビュー、ファイル編集、ファイルの素早い選択などを改善しました。
- **モバイル表示**：小さい画面での配置と操作を見直しました。
- **設定とショートカット**：設定画面内の検索、キー操作の設定、各種表示設定を整理しました。
- **セッション管理**：履歴の管理・保管と取り込みに関する操作を改善しました。
- **チーム表示**：複数担当の状況や担当画面への移動を調整しました。

## 配布とライセンス

- 配布物の検証手順と Windows デスクトップ版のパッケージ処理を更新しました。
- ライセンス表記と、Pi 由来のコードに関する表示を整理しました。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@0.1.9
hasilan-code setup
hasilan-code
```

Windows デスクトップ版は添付の `Hasilan-Code-0.1.9-win-x64.exe` を利用できます。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v0.1.9/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

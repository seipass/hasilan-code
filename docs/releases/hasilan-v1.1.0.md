Hasilan Code の初期公開リリースです。Pi を基盤とする、ローカルで動作する AI コーディング環境を提供します。

## このバージョンの主な機能

- **AI チャット**：モデルや推論の強度を選択し、会話と実行したツールの結果を確認できます。
- **複数の AI による作業**：チーム実行と「百鬼夜行」で実装・検証などの担当を分けられます。
- **Goal と Canvas**：継続的な目標の実行と、項目同士をつないで設計を整理する画面を備えています。
- **開発用の画面**：ファイル閲覧、ターミナル、ブラウザー操作などを同じ画面から利用できます。
- **独立した保存先**：設定と会話履歴を本家 Pi と分けてローカルに保存します。

## 利用上の注意

ローカルの単一ユーザー向けです。AI の端末操作やファイル操作は、起動したユーザーの権限で実行されます。信頼できる環境で使用してください。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@1.1.0
hasilan-code setup
hasilan-code
```

GitHub Releases には配布用アーカイブとインストーラーを添付しています。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v1.1.0/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

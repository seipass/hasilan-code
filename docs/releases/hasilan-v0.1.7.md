Windows デスクトップ版の配布に対応し、アプリとしての起動と設定の保存を改善しました。

## Windows デスクトップ版

- **専用インストーラー**：Windows x64 向けのデスクトップ版を追加しました。Web 版と同じ画面で操作できます。
- **起動と画面の統合**：デスクトップ用のウィンドウ、ブラウザー表示、起動処理を整えました。
- **動作検証**：アプリ起動から画面表示までを確認するテストと、配布パッケージの検証手順を追加しました。

## 画面と設定

- **設定の保存**：画面の好みや設定を保存し、Web 版とデスクトップ版で共有する構成にしました。
- **操作画面の改善**：モデル選択、詳細表示、添付ファイル、ブラウザー画面などを調整しました。
- **実行環境の保護**：プロフィールの同時利用を検出する仕組みなど、デスクトップ利用時の処理を整理しました。

## インストール・更新

Node.js 22.19.0 以上を用意し、以下のコマンドでこのバージョンを指定して導入できます。

```sh
npm install --global --ignore-scripts hasilan-code@0.1.7
hasilan-code setup
hasilan-code
```

Windows デスクトップ版は添付の `Hasilan-Code-0.1.7-win-x64.exe` を利用できます。詳しくは[このバージョンの導入手順](https://github.com/seipass/hasilan-code/blob/hasilan-v0.1.7/README.md)を参照してください。認証情報と会話履歴はインストール先とは別に保存されます。配布物の検証には添付の `SHA256SUMS` を使用してください。

[前のリリースからの変更一覧](https://github.com/seipass/hasilan-code/compare/hasilan-v0.1.6...hasilan-v0.1.7)

# ローカル開発モード

ローカル開発モードでは、起動トークンを使わずにWeb画面を開けます。事前に[ソースからの起動手順](../README.md#ソースから起動する開発者向け)に従って配信用ファイルをビルドし、リポジトリのルートで次のコマンドを実行してください。

```sh
npm run web:dev
```

[http://127.0.0.1:3080/](http://127.0.0.1:3080/) をブラウザーで開きます。ポートや作業フォルダーを指定する場合は、次のようにします。

```sh
npm run web:dev -- --port 3081 --cwd /path/to/project
```

このコマンドは `NODE_ENV=development` と `--dev` を指定します。両方を指定した場合だけ画面の認証を省略し、接続先と接続元をループバックに限定します。Host、変更APIのOrigin、WebSocketのOriginは引き続き検査します。`--lan` との併用はできません。

通常の `npm run web` と配布版の起動には、認証付きURLが必要です。AIモデルのプロバイダー認証は、開発モードでも必要です。

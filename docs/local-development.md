# ローカル開発で認証なしで開く

ソースの配信用ファイルを用意した状態で、リポジトリのルートから起動する。

```sh
npm run web:dev
```

[http://127.0.0.1:3080/](http://127.0.0.1:3080/) をそのまま開ける。起動トークンや認証Cookieは不要。ポートや作業フォルダーは `npm run web:dev -- --port 3081 --cwd <directory>` で指定する。

このコマンドは `NODE_ENV=development` と `--dev` を設定する。両方が明示された場合だけ認証を省略し、接続先と接続元をループバックに限定する。Host・変更APIのOrigin・WebSocketのOriginの検査は継続する。`--lan` との併用は起動エラーになる。

通常の `npm run web` と配布版の通常起動では、引き続き認証付きURLが必要。モデルのプロバイダー認証は開発モードでも必要。

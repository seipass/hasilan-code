# ローカル開発モード

ローカル開発モードでは、ワンタイム起動トークンを入力せずに Web UI を開いて動作確認できます。

事前に [ソースコードからの起動手順](../README.md#ソースコードから起動する開発者向け) に従って配信用アセットをビルドした上で、リポジトリのルートで以下のコマンドを実行してください。

```sh
npm run web:dev
```

起動後、ブラウザーで [http://127.0.0.1:3080/](http://127.0.0.1:3080/) に直接アクセスできます。

リッスンポートや作業フォルダー（ワークスペース）を変更する場合は、オプションを付与します。

```sh
npm run web:dev -- --port 3081 --cwd /path/to/project
```

### 仕様と制約事項

- `npm run web:dev` は `NODE_ENV=development` と `--dev` フラグを指定して起動します。この両方が設定されている場合のみ画面認証が省略され、接続先および接続元がループバック（`127.0.0.1`）に制限されます。
- HTTP Host ヘッダー、変更系 API の Origin、WebSocket の Origin 検証は引き続き有効です。
- `--lan` オプションとの併用はできません。
- 通常起動（`npm run web`）やパッケージ配布版では認証トークン付き URL が必須となります。
- AI モデルのプロバイダー認証（API キー等）は開発モードでも必要です。
